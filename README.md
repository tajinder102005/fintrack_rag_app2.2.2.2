# fintrack.Ai

AI-powered personal finance tracker for India — track every rupee, set budgets, and get Gemini-powered financial advice.

## Features

- Dashboard with balance, income, expenses and charts
- Transactions, budgets, notifications
- AI Coach (Gemini) with personalized insights
- Google and GitHub OAuth
- MongoDB Atlas backend

## Quick start

```bash
npm install
cp .env.example .env
npm run dev
```

- Frontend: http://localhost:3000
- API: http://localhost:5000
